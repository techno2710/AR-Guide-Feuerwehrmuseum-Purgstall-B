# Installation

## Voraussetzungen

- Python 3.11 oder neuer
- `pip` (kommt mit Python)
- Optional: `git`, falls du aus dem Quellcode installieren willst

## Installation über pip

```bash
pip install taskflow
```

## Installation aus dem Quellcode

```bash
git clone https://github.com/beispiel/taskflow.git
cd taskflow
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## Installation prüfen

```bash
taskflow --version
```

Wenn eine Versionsnummer erscheint, war die Installation erfolgreich.
