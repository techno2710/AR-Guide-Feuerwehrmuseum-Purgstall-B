# TaskFlow

TaskFlow ist ein kleiner Aufgabenmanager für die Kommandozeile mit
optionaler REST-API.

## Was kann TaskFlow?

- Aufgaben anlegen, bearbeiten und abhaken
- Aufgaben mit Tags und Fälligkeitsdatum versehen
- Daten lokal in SQLite speichern
- Alles zusätzlich über eine REST-API steuern

## Schnellstart

```bash
pip install taskflow
taskflow add "Wiki schreiben" --tag doku
taskflow list
```

> **Tipp:** Mit dem Suchfeld links oben findest du Inhalte schnell.
